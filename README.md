# ✨ AeroSketch – AI Spatial Drawing App

AeroSketch is an AI-powered application that enables users to draw in the air using hand gestures. It uses computer vision and real-time tracking to convert hand movements into digital drawings on a virtual canvas.

## 🚀 Features
- 🖐️ Hand gesture recognition
- 🎨 Real-time air drawing
- 🧠 AI-based motion tracking
- 💻 Interactive UI
- ⚡ Smooth performance

## 🛠️ Tech Stack
- JavaScript / TypeScript
- Vite
- HTML / CSS
- (Optional: MediaPipe / OpenCV)
